# Sense Street

> Sense Street provides production-grade AI workflow automation for capital markets, turning unstructured OTC trading conversations across Bloomberg, Symphony and ICE into structured, real-time market data — RFQs, orders and sentiment — for the trading desk. No public API specification is published; API access (a batch processing API and WebSocket streaming endpoints, secured with SSO and role-based access) is gated behind a sales/onboarding contact. This llms.txt is generated by API Evangelist from public pages.

## Products
- AI-Enhanced Blotter: captures untraded signals from broker conversations
- Quotebook: converts conversations into structured market data for algo models and alerts
- Workflow Automation: handles multi-party conversations across asset classes (Fixed Income, Commodities)
