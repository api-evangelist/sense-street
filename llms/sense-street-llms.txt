# Sense Street

> Sense Street turns unstructured OTC trading conversations — broker chat on Bloomberg, Symphony, ICE and Eikon — into structured, real-time market data for the capital-markets desk: RFQs, orders, quotes and sentiment, delivered through an AI-Enhanced Blotter and a Quotebook that feeds algo models and alerts. Sense Street Limited is registered in London (1 Phipp Street, EC2A 4PS) with an engineering office in Kraków, Poland, and is backed by Seedcamp and Speedinvest. This llms.txt is generated by API Evangelist from public sources; it is not published by Sense Street.

## API surface

Sense Street ships a real REST API. It publishes no OpenAPI to the public web — its own Batch API page says "for exact schemas and edge-cases, refer to the Swagger/OpenAPI spec", and that spec is issued to customers rather than served publicly. What follows is read off the first-party Python client the company publishes to PyPI, and confirmed against live probes.

- Base path: `/api/v1`, appended to a per-tenant host issued at onboarding
- Host pattern: `https://{tenant}.api.sensestreet.com` (production) and `https://{tenant}.api.test.sensestreet.com` (test) — both appear as SANs on the company's wildcard certificate; the bare `api.sensestreet.com` does not resolve
- Auth: client-signed RS256 JWT bearer (`aud: api.sensestreet.com`, 15-minute expiry) plus the caller's PEM public key in an `X-key` header. Not OAuth — there is no authorization server and no scopes
- Network: access requires VPN connectivity and static allowlisted source IPs
- Errors: HTTP 401 `Invalid or missing token` as plain text; not RFC 9457
- No rate-limit headers, no idempotency contract, no pagination, no webhooks

Operations, as called by the first-party client:

- `GET /api/v1/ping` — connectivity check
- `GET /api/v1/ping_auth` — authorised connectivity check
- `POST /api/v1/predict_rfqs` — extract RFQs from a full conversation
- `POST /api/v1/predict_chat_snippet_rfqs` — extract RFQs from a chat snippet
- `POST /api/v1/conversations` — upload conversation files for batch processing; returns a `file_id` per file
- `GET /api/v1/conversations/status/{file_id}` — poll processing status
- `GET /api/v1/conversations/file/{file_id}` — download processed conversations (`target`, default `RFQ_CREDIT`)
- `GET /api/v1/conversations/history` — list uploads in a time range (`since`, `until`)
- `POST /api/v1/bonds` — upload bond reference data
- `POST /api/v1/upload_file` — upload electronic RFQ (`file_type=ERFQ`) records

A WebSocket API is also documented, providing real-time quote and market-activity feeds subscribable by commodity — oil, carbon, EMEA gas, US gas. No AsyncAPI is published and the channel contract is not public.

## SDKs

- Python — `sensestreet` on PyPI, first-party (author Sense Street, engineering@sensestreet.com), Apache-2.0, v1.0.16 published 2025-10-07: https://pypi.org/project/sensestreet/
  - `pip install sensestreet`
  - Also ships client-side anonymisation helpers that strip LoginName, names, UUID, FirmNumber, AccountNumber and e-mail fields out of Bloomberg chat XML before upload
- No JavaScript/npm, Go, Java, Ruby, PHP or .NET client is published
- No CLI, no MCP server, no A2A agent card

## Products

- AI-Enhanced Blotter — captures untraded signals from broker conversations
- Quotebook — converts conversations into structured market data, price discovery and alerts; >95% claimed precision, full broker coverage across ICE, Eikon and Bloomberg
- Workflow automation across multiple asset classes (Fixed Income, Commodities) and languages
